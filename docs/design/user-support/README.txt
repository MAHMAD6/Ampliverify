AMPLIVERIFY USER-END SUPPORTING PAGES — SINGLE BATCH

Included
1. Billing & Plan
2. Notifications
3. Help & Support
4. Getting Started / Onboarding

Important navigation decisions
- Billing & Plan already belongs in the locked user navigation order and is refined here rather than added as a new module.
- Notifications remains a Settings subpage and also connects to the header bell.
- Help & Support is a utility destination near the bottom of the shell, not a core SEO module.
- Getting Started is dismissible onboarding and is NOT a permanent sidebar item.

Production rules
- No fabricated billing, credit, invoice, audit, support-ticket, or onboarding-progress data.
- User billing state comes from the billing backend/provider.
- Notification state comes from real account/product events.
- Support history is shown only if support-ticket persistence exists.
- Onboarding progress is computed from real user actions.

This batch is intended to close the remaining user-end supporting-page gap without expanding V1 scope.
